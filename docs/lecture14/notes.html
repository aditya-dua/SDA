Section 1: What Is Grafana?

The Problem It Solves

In Modules 2 and 3, you built the full backend: Kafka producers, consumers, MongoDB storage, alert routing, and windowing. All that work produces data — but the data lives in a database only engineers can query. Grafana closes this gap. It turns database queries into visual panels that refresh automatically, putting your streaming data in front of the people who need to act on it.

What It IsWhat It Isn't
A dashboard and visualisation platformA database
A query builder (UI on top of your data)A streaming system
An alerting layer with notification routingA replacement for MongoDB/Kafka
Open source + free for self-hosted useAn analytics/BI tool (that's Metabase, Tableau)

Understanding this tool positions you to have meaningful conversations about data infrastructure — as a manager, analyst, or product leader.

Section 2: The Grafana Mental Model

Four Building Blocks

  1. Data Source — A connection to a database. Grafana supports 50+ natively (Prometheus, InfluxDB, MySQL) and 100+ via community plugins (MongoDB, BigQuery, Snowflake).
  2. Query — The question you're asking of the data source. Written in the data source's native language (MongoDB aggregate pipeline, SQL, PromQL).
  3. Panel — One visual unit: one chart, one number, one table. Each panel has exactly one query and one visualisation type.
  4. Dashboard — A collection of panels on a grid. Has a time range selector and auto-refresh interval.

Time as a First-Class Citizen

Unlike static BI tools, Grafana treats time as the primary dimension. Every dashboard has a time range (last 5 min, last 1 hour, custom). This makes it ideal for streaming data — you can zoom into the exact window when an alert fired.

Install Grafana with Docker

docker run -d \
  --name grafana \
  -p 3000:3000 \
  -e GF_SECURITY_ADMIN_PASSWORD=admin \
  grafana/grafana-oss:latest

# Open: http://localhost:3000
# Login: admin / admin  (Grafana will prompt you to change it)

docker exec -it grafana grafana-cli plugins install grafana-mongodb-datasource

Section 4: Create the Sample Dataset

Everyone will first use the same small dataset so that differences in Kafka history do not interrupt the lab. The collection contains ten one-minute observations for both INFY and TCS.

Dataset Fields

FieldExampleBusiness Meaning
symbolINFYCompany being monitored
event_timeDate valueWhen the market observation occurred
price1512.50Observed share price in rupees
volume1320Shares traded during the interval

Seed MongoDB Atlas

  1. In Atlas, open Browse Collections and select the sda_course database.
  2. Create a collection named grafana_stock_demo.
  3. Open MongoDB Compass, connect to the same cluster, and click the embedded >_ MONGOSH button.
  4. Paste and run the script below. It creates dates relative to the current time, so Grafana's “Last 30 minutes” filter will work whenever the lab is run.
use sda_course

db.grafana_stock_demo.deleteMany({})

const prices = {
  INFY: [1498, 1502, 1500, 1506, 1511, 1508, 1514, 1518, 1515, 1521],
  TCS:  [3820, 3814, 3818, 3825, 3831, 3827, 3835, 3842, 3838, 3846]
}

const now = Date.now()
const rows = Object.entries(prices).flatMap(([symbol, values]) =>
  values.map((price, index) => ({
    symbol,
    event_time: new Date(now - (9 - index) * 60 * 1000),
    price,
    volume: 900 + index * 70 + (symbol === "TCS" ? 120 : 0)
  }))
)

db.grafana_stock_demo.insertMany(rows)
db.grafana_stock_demo.find().sort({event_time: -1}).limit(4)

Checkpoint: The final command should display four documents. Confirm that event_time is stored as a Date, not as text. Grafana needs a real date field for time filtering.

Section 5: Hands-On Lab — Stock Market Pulse Dashboard

Scenario: You are the operations manager for a retail investment platform. During market hours, your team needs one screen that answers three questions: What is INFY's latest price? What direction is it moving? What were the latest observations?

Panel A — Latest Price

Stat visualisation for a fast executive read.

Panel B — Price Trend

Time Series visualisation to reveal direction.

Panel C — Recent Data

Table visualisation for operational detail.

Step 1 — Create and Name the Dashboard

  1. Go to Dashboards → New → New Dashboard.
  2. Select Add visualisation, then choose the MongoDB data source.
  3. Click Save dashboard and name it Stock Market Pulse — Lecture 14.
  4. Set the dashboard time range to Last 30 minutes.

Step 2 — Panel A: Latest INFY Price

This panel answers: “What is the latest price right now?”

{
  "collection": "grafana_stock_demo",
  "aggregate": [
    { "$match": { "symbol": "INFY" } },
    { "$sort": { "event_time": -1 } },
    { "$limit": 1 },
    { "$project": { "_id": 0, "time": "$event_time", "value": "$price" } }
  ]
}
  1. Choose the Stat visualisation.
  2. Set the title to Latest INFY Price.
  3. Under Standard options, set the unit to Currency → Indian Rupee and decimals to 2.
  4. Click Apply. The panel should display ₹1,521.00.

Step 3 — Panel B: INFY Price Trend

This panel answers: “Is the price rising, falling, or stable?”

{
  "collection": "grafana_stock_demo",
  "aggregate": [
    { "$match": { "symbol": "INFY" } },
    { "$sort": { "event_time": 1 } },
    { "$project": { "_id": 0, "time": "$event_time", "value": "$price" } }
  ]
}
  1. From the dashboard, click Add → Visualisation.
  2. Choose Time Series and title it INFY Price Trend.
  3. Set the unit to Indian Rupee and decimals to 2.
  4. Under Legend, select Table and display Last, Min, and Max.
  5. Click Apply. The line should generally rise from ₹1,498 to ₹1,521.

Step 4 — Panel C: Recent Market Observations

This panel answers: “What are the latest underlying records?”

{
  "collection": "grafana_stock_demo",
  "aggregate": [
    { "$sort": { "event_time": -1 } },
    { "$limit": 10 },
    { "$project": {
        "_id": 0,
        "time": "$event_time",
        "symbol": 1,
        "price": 1,
        "volume": 1
    }}
  ]
}
  1. Add another visualisation and choose Table.
  2. Set the title to Recent Market Observations.
  3. Use Organize fields transformation to order the columns: time, symbol, price, volume.
  4. Rename the displayed headings to Time, Symbol, Price (₹), and Volume.
  5. Click Apply.

Step 5 — Arrange and Refresh

  1. Place the latest-price Stat panel at the top left and keep it small.
  2. Place the Time Series beside it and make it the widest panel.
  3. Place the Table across the full width below the charts.
  4. Set dashboard refresh to 10 seconds and save.

Important: Refreshing does not create new data; it only reruns the queries. The seeded chart remains unchanged until new documents arrive. When the Lecture 8/9 producer and consumer are running, the same dashboard pattern becomes live.

Step 6 — Read the Dashboard Like a Manager

  1. Observe: INFY closes the sample at ₹1,521, up ₹23 from the first observation.
  2. Explain: The time series shows a generally positive direction with two short pullbacks.
  3. Check: The table confirms that both symbols have recent records and increasing volume.
  4. Decide: Continue monitoring rather than escalating; a trend alone is not an alert without a defined threshold.

Success checklist: Your dashboard has three titled panels, uses the Last 30 minutes range, shows ₹1,521 as the latest INFY price, and can be explained in one sentence to a business stakeholder.

Key Takeaways

✓ Key Takeaways — Lecture 14

  1. Grafana is the visual layer — it sits on top of databases, not inside them
  2. Four building blocks: Data Source → Query → Panel → Dashboard
  3. Time is central — dashboards have a time range and auto-refresh, making them live
  4. A useful dashboard begins with business questions, not chart types
  5. Stat, Time Series, and Table panels answer summary, trend, and detail questions
  6. Auto-refresh reruns queries; the source pipeline is what creates new data
