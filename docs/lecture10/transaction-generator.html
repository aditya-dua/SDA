How to Run

  1. Download both files into the same folder.
  2. Run the downloaded configuration: python generate_transactions_config.py.
  3. The generator creates transactions_custom.csv.
  4. Repeated runs continue transaction IDs using a local sequence file, so database primary keys do not collide.
